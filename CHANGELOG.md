# Changelog

## [0.2.0] - 2026-10-30

### Added

- Added the bilingual, UXML/USS-only Learning Lab Sample with pages for source navigation, cascade inspection, and parent-child layout diagnostics.
- Added localized **Open Examples** menu entries that import the native Unity Sample on first use and open the page matching the plugin language.
- Added first-open canvas setup for menu-launched examples while preserving existing document settings and imported practice edits.
- Added the independent example-assets PowerShell test runner.
- Added screenshot walkthroughs for all three Learning Lab pages in both guides; documentation images ship with the Sample and compatibility export.

### Fixed

- Matched the English README and Learning Lab walkthroughs to dedicated English sample and diagnostics screenshots.

- Added the MIT license to the repository and UPM package, and updated package license metadata.
- Replaced placeholder installation URLs and outdated pre-publication notes in both languages with the public repository address.

## [0.1.0] - 2026-10-30

### Migration baseline

- Moved the existing UI Builder Navigator implementation out of the SEC Lab project into the embedded UPM package `Packages/com.poorl.ui-builder-navigator`.
- Preserved the existing Editor assembly, namespaces, preferences, menu path, and Chinese/English interface behavior.
- Added the Unity 6000.3.27f1 development project and standalone repository documentation.
